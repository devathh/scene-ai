# Scene AI Frontend

Minimalist white-themed frontend for the Scene AI project.

## Features
- Clean, minimalistic UI in white theme
- User Authentication (Login/Register)
- Scenario Generation via AI
- Real-time status polling for generated scenes
- Responsive design

## Usage
Simply open `index.html` in a browser. Ensure the backend API is running on the same host or configured for CORS.

## API Integration
The frontend expects the backend to be available at the relative path `/api/v1`.
